# 灰燼與星紋（Ashes & Astral Runes）

繁體中文西幻 D&D 風格互動式文字冒險遊戲 MVP，採用暗黑奇幻、羊皮紙與燙金邊框視覺設計，並以零依賴現代化 HTML5 / CSS3 / ES6 Modules 實作。

## 核心特色

- **創角系統**：自訂或隨機西幻姓名、權重機率抽選種族（人類 90%、矮人 3%、精靈 1%、魔族 1%）、四大職業（戰士、法師、遊俠、牧師），以及標準 D&D **27 點購點制**（即時計算六大屬性調整值與初始 HP）。
- **三欄式冒險介面**：
  - 左欄：角色狀態卡（動態 HP 條、六大屬性調整值、職業被動與種族天賦）
  - 中欄：羊皮紙主劇情顯示區與互動選項區
  - 右欄：背包物品欄（含藥水即時飲用回血與裝備／關鍵道具）與冒險日誌
- **1d100 檢定系統**：選項標註檢定屬性與難度（如 `[魅力檢定 DC 45]`），點擊彈出 1d100 擲骰動畫，加總屬性調整值與被動／線索加值，明確判定 **大成功 (100)、成功、失敗、大失敗 (1)** 並推進不同分支。
- **完整測試劇本《斷星遺跡的委託》**：涵蓋「酒館接任務 → 幽影林地伏擊 → 斷星石門與星象解謎 → 星蝕密室決戰 → 五重結局」。

## 本地啟動方式

在 Windows PowerShell 執行內建零依賴靜態伺服器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1 -Port 8080
```

接著在瀏覽器開啟 `http://localhost:8080/` 即可遊玩。
